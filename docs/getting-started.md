# Getting Started

## Recommended: Docker (one command)

```bash
git clone https://github.com/mansabhairodagi/Dungeonmaind.git
cd Dungeonmaind
chmod +x start-docker.sh   # macOS / Linux, first time only
./start-docker.sh
```

Windows:

```powershell
.\start-docker.ps1
```

Then open `http://localhost:5173`. See [Docker Deployment](docker.md) for details.
